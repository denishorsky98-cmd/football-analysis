# Football Analysis 🎯

Analýza futbalistov zo svetového pohára podľa pozícií.

## 📊 Čo to Je?

Tento projekt analyzuje dáta o útočníkoch (FW) z futbalu.

### Grafy:
1. **TOP 10 Tímov** - Ktoré tímy dávajú najviac gólov?
2. **Distribúcia Výšky** - Aká je priemerná výška útočníkov?
3. **Góly vs. Skúsenosť** - Majú skúsenejší hráči viac gólov?
4. **TOP 10 Hráčov** - Kto sú najlepší skórujúci hráči?

## 📁 Súbory:
- `analysis.py` - Python script s analýzou
- `SquadLists.csv` - Dataset s hráčmi
- `football_analysis.png` - Všetky grafy

## 🚀 Ako Spustiť:

```bash
python analysis.py
